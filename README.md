# knowledge-capricorn

Wissenspaket von AIbex AIBOS, Version 0.2.0: die Regel Capricorn. Jede Antwort der KI beginnt mit dem Präfix „🐐 “, der User wird mit Du angeredet. Die Regel liegt in `knowledge/@Rule/Capricorn/Capricorn.md` und wird nach dem Holen geladen, als läge sie in `@/@Rule/` des Masterspace (Spec 02, K6).

Ein zugeordneter Assistent mit eigenem Präfix (z. B. Anja) überschreibt das Präfix der Regel; das ist gewollt.

## Voraussetzung

AIBOS v0.7, Vault an AIBOS gebunden.

## Holen

```bash
aibos --fetch knowledge-capricorn
```

Teil der Distribution `distribution-capricorn` ab 0.5.0.
